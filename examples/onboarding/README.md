# COAD Onboarding Example

This is the smallest complete COAD adoption shape:

- `AGENTS.md` tells agents to run `coad check .`;
- root `MODULE_CONTRACT.md` describes one real module with `workcell.context_path`;
- `onboarding-checkout/README.md` gives module context;
- `onboarding-checkout/TODO.md` gives current module work.

Run from this directory:

```bash
coad check .
```

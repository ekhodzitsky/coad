# docs/archive

Pre-v0.9 prose and code, kept for historical context only. None of this
is required reading for using COAD. It documents what COAD tried to be
between v0.1 and v0.8 before it collapsed to a methodology in v0.9.

Material that survived into v0.8 (the "standard + validator" era) and
was archived when COAD became prose-only:
